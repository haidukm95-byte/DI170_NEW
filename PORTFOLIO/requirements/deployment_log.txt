3. Configure the service
Setting	Value
Root Directory	PORTFOLIO
Environment	Node
Build Command	npm install
Start Command	npm start
Instance Type	Free (fine for a static portfolio)
Root Directory is the important one — it tells Render to cd PORTFOLIO 
before running build/start, so node server/server.js resolves correctly 
and express.static serves PORTFOLIO/index.html, css/, js/ as expected.

4. Environment variables
Add none for PORT — Render injects its own PORT env var at runtime, and your code already does process.env.PORT || 3000, so it picks that up automatically. Don't hardcode a port.

Your server/.env file is git-ignored (confirmed in the root .gitignore), so it won't be pushed — that's correct, since it's only needed for local dev.
