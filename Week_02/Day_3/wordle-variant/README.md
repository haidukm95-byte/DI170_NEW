# Dev Wordle

A terminal-themed Wordle variant focused on programming terms. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- 100+ programming terms across multiple categories:
  - Frontend & Frameworks (React, Redux, Props, State, etc.)
  - Backend & Databases (Cache, Query, Redis, Mongo, etc.)
  - Programming Concepts (Class, Async, Scope, Array, etc.)
  - DevOps & Tools (Docker, Nginx, Cloud, Build, etc.)
  - Version Control (Merge, Clone, Stash, Diff, etc.)
  - And more!

- Terminal/IDE-inspired aesthetic with dark theme
- Color-coded feedback system (Green, Yellow, Gray)
- Physical keyboard + on-screen keyboard support
- Responsive design

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to play the game.
